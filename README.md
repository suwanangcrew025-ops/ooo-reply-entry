# Funniest One-Line Out-of-Office Reply

An entry for the [make.fun bounty "Funniest One-Line Out-of-Office Reply"](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8): one line, the sort a person sets before going away, judged two at a time on humour and freshness.

## The reply

> Out of office until Monday. The fern on my desk is in charge now; it has survived three managers, two mergers, and one fire drill it slept through.

147 characters, inside the 1–160 gate. It reads like a real away message, and the joke turns on what the fern has survived — three managers, two mergers, and a fire drill it slept through.

## How it runs

`main.py` (Python standard library only) reads `ooo.txt` and writes it unchanged to `/output/entry.txt`, where the sealed gate scorer reads it. Deterministic: the same bytes every run.
